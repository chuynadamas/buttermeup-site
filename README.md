# ButterMeUp! — landing page

Marketing page for the iOS game **ButterMeUp!**, served with GitHub Pages
at https://chuynadamas.github.io/buttermeup-site/

Support and privacy pages live in a separate repo
(`buttermeup-support`), because those two URLs are referenced from the
App Store listing and must not move.

## On launch day

The App Store button is in its pre-release state. When the app goes
live, edit `index.html`:

- remove the `pending` class from the `<a class="cta pending">` link
- change its text to "Download on the App Store"
- delete the `cta-note` line ("in review")

The href already points at the final product page (id6780270055).
